📱  ดาวน์โหลด Bluefy (App Store)

1. ติดตั้ง Bluefy จาก App Store
2. เปิด Bluefy แล้วไปที่ไฟล์ HTML นี้
3. กด Connect แล้วเลือก HC-05/HC-06 ของหุ่นยนต์
4. ควบคุมหุ่นยนต์ได้เลย! 🤖

L เลี้ยวซ้าย ◀
R เลี้ยวขวา ▶

คู่มือการใช้งาน

Android / Chrome

1. เปิดไฟล์ HTML นี้ใน Chrome บน Android

2. กด CONNECT BLUETOOTH

3. เลือก HC-05 หรือ HC-06 ของหุ่นยนต์

4. กดปุ่มควบคุมค้างไว้เพื่อเคลื่อนที่

5. ปล่อยมือเพื่อหยุด


iPhone / iPad

1. ดาวน์โหลด Bluefy จาก App Store

2. เปิดแอป Bluefy แล้วเปิดไฟล์ HTML นี้

3. Connect และควบคุมได้เลย


หมายเหตุ: ถ้าคำสั่ง F/B/L/R/S ไม่ตรงกับ Arduino ของคุณ สามารถแก้ใน JavaScript ได้
